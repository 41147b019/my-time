# 任務紙條 · 為挑選器寫一頁使用說明 / 2026-10-12

給：隊員・太魯閣　　來自：領隊・洄瀾　　模式：手動接力

## 做什麼 / What

為 `workspace/shared/` 裡的「課間我想做什麼？」挑選器（`campus-picker.html`）寫**一頁使用說明**，包含「怎麼用」＋「三件做不到的事」。

## 只能用這些資料 / Sources

只能用 `workspace/shared/` 裡的檔案：

- `campus-picker.html`（頁面上的介面文字與程式邏輯）
- `activities.json`（12 個活動的資料）
- `README.md`

**檔案裡沒有的就不要寫。** 不要自己編功能、編活動、編學校名稱。shared 只讀，不要改。

## 怎麼引用畫面 / How to refer to the page

小隊長（人類）和領隊都看不到這個網頁的「章節編號」，所以**不要寫「第 0 節」「上方」「下面」這類位置詞**。一律用頁面上看得到的文字來指認，例如：

- 標題：「What can I do between classes?」（中文介面為「課間我想做什麼？」）
- 三個條件區塊：「Location／地點」「Available time／可用時間」「Energy／體力」
- 按鈕：「Pick for me／幫我選」「Reset filters／重設條件」「Clear history／清除紀錄」，以及切換語言的按鈕（英文介面上顯示「中文」，中文介面上顯示「English」）
- 結果框：一開始顯示提示句，選不到時顯示「No matching activities.／沒有符合條件的活動。」
- 歷史區塊：「Last 5 picks (newest first)／最近 5 次（最新在上）」，下面有「No picks yet.／還沒有紀錄。」

引用時中英並列最保險，例如：按「Pick for me」（中文介面為「幫我選」）。

## 格式 / Format

- 一個 Markdown 檔，繁體中文（台灣用語）為主，頁面上的介面原文保留英文原文＋中文。
- 建議結構（可微調，但都要涵蓋）：
  1. **這是什麼**：一句話＋「虛構教學活動，不是學校正式公告」的提醒（頁面上就有這句）。
  2. **怎麼用**：照操作順序寫清楚——選三個條件（每個條件有哪些選項）→ 按「幫我選」→ 看結果框 → （可選）切換語言、按「重設條件」、按「清除紀錄」。順帶講清楚：時間篩選是「所需時間 ≤ 你選的時間」；紀錄只留最近 5 次、最新在上。
  3. **三件做不到的事**：見下方指定的三件，每件一句「為什麼」，理由要對得回檔案。
  4. 結尾一行：這是虛構教學用的活動資料。

## 三件做不到的事（請用這三件）/ The three cannot-dos

1. **記不住你的紀錄**——重新整理或關掉網頁，「最近 5 次」就空了。（程式裡 history 只存在記憶體，註解寫明 "not saved after reload"。）
2. **不能自己加、改、刪活動**——12 個活動寫死在頁面裡，和 `activities.json` 一樣，畫面上沒有任何新增/編輯/刪除活動的地方。
3. **不會推薦時間不夠的活動**——只會從「所需時間 ≤ 你選的時間」的活動裡挑；全部都不夠時，直接顯示「No matching activities.／沒有符合條件的活動。」，不會硬塞一個。

## 怎樣算做完 / Done looks like

- `workspace/outbox/` 裡有一個**新檔**（不要覆蓋任何既有檔），檔名建議：`20261012-picker-user-guide.md`。
- 內容涵蓋：三個條件區塊的全部選項、四個按鈕（幫我選／重設條件／清除紀錄／切換語言）、結果框的兩種顯示、歷史規則（最近 5 次、最新在上、清除後歸零）。
- 「做不到的三件」就是上面那三件，理由都能對回 `campus-picker.html` 或 `activities.json`。
- 沒有任何一句話是三個來源檔裡找不到依據的。
- 檔案最後一行是交接句：做了什麼、哪裡要注意、能不能直接用。
