# 任務紙條 · 做一個 BMI 計算機 / 2026-10-12

給：隊員・太魯閣　　來自：領隊・洄瀾　　模式：手動接力

## 做什麼 / What

做一個**BMI 計算機**：單一 HTML 檔（CSS／JS 都內嵌，雙擊就能開，不引用任何外部資源或函式庫）。小隊長已拍板：判定用**台灣衛福部成人標準**，介面**中英雙語可切換**。

## 存檔 / Where

- 新檔案：`workspace/outbox/20261012-bmi-calculator.html`
- `workspace/shared/` 只讀。想參考挑選器的版面風格可以，但**不要動 shared 裡任何檔案**，也不要動 outbox 裡既有的 v1～v4。

## 功能規格 / Specs

1. **輸入**：身高（公分）、體重（公斤）兩個數字欄位＋一個「計算」按鈕。
2. **計算**：BMI ＝ 體重(kg) ÷ 身高(m)²。顯示時**四捨五入到小數點一位**。
3. **判定（台灣衛福部成人標準，照這組分界，邊界值歸入上方區間）**：
   - BMI < 18.5 → 過輕 Underweight
   - 18.5 ≤ BMI < 24 → 正常 Normal
   - 24 ≤ BMI < 27 → 過重 Overweight
   - 27 ≤ BMI < 30 → 輕度肥胖 Mild obesity
   - 30 ≤ BMI < 35 → 中度肥胖 Moderate obesity
   - BMI ≥ 35 → 重度肥胖 Severe obesity
4. **結果畫面**：顯示 BMI 數值＋判定等級，另顯示「此身高的健康體重範圍」＝ BMI 18.5～24 對應的公斤數（一樣四捨五入到小數點一位）。
5. **雙語切換**：預設繁體中文（`lang="zh-Hant-TW"`，台灣用語）；切換按鈕在中文介面顯示「English」、在英文介面顯示「中文」，按下去整頁文字都換（可參考 `campus-picker.html` 的做法）。判定等級的中英文都要有。
6. **輸入檢查**：空白、非數字、負數、明顯不合理的值（身高建議 50–250 cm、體重建議 10–300 kg 之外）都不要算，顯示清楚的錯誤提示；不允許出現 NaN 或 Infinity。
7. **兩句免責提醒（頁面上要有）**：
   - 本工具採台灣衛福部成人 BMI 分級，**兒童青少年、孕婦不適用**。
   - 僅供參考，不是醫療建議。

## 隱私 / Privacy

- **不儲存任何輸入**：不用 localStorage、不發網路請求、不記錄身高體重。算完即走。
